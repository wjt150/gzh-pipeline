# 写稿任务（自动化用）

> 把这份内容整段作为 automation 的 prompt。它会自己选题、读原文、写稿、自检、存草稿、推到二维码。
> 配套脚本在 `scripts/`，规范在 `组件库.md` 与 `排版规范.md`。

## 你要做的事（按顺序，一步都别跳）

1. **备稿**
   ```bash
   python scripts/gzh_prep.py
   ```
   - 退出码 `0`：成功，读它输出的 `out_dir`
   - 退出码 `2`：**今日无达标选题**（这是正常结果，不是错误）→ 直接结束，一句话说明最高分那条差多少分
   - 退出码 `3`：急停（`STOP_AUTO` 存在）→ 静默结束
   - 退出码 `10`：另一实例在跑 → 结束

2. **读原文**
   打开 `<out_dir>/source.md`。**必须先读完再写**，不许凭标题推测内容。
   同时读 `<out_dir>/briefing.json`：里面有点评星级、要点、形态建议、字数区间、源链接。

3. **写正文 `body.html`**
   - 照 `组件库.md` 里对应形态的拼法（`form` 字段给了 A–E）
   - **只许 5 个标签**：`section` / `span` / `strong` / `br` / `img`，属性只许 `style`
   - 每段一个 `<section>`；文字样式写在 `<span style>` 上；`<strong>` 与 `<span>` 平级
   - 字数按 `chars_range`；加粗 6–10 处；全文只有一个强调色 `#1a4d8f`
   - 文末必须有「信息来源：…」那一段
   - **不逐段照抄原文**：中文编译/聚合，引用单篇核心段落 ≤200 字并注明出处

4. **填 `manifest.json`**
   - `title`：≤64 字，直给结论，别用「震惊」类词
   - `summary`：60–120 字
   - `body_html_path` 与 `cover_path` 已填好，不要动

5. **自检（两道，都必须过）**
   ```bash
   python scripts/gzh_lint.py --manifest <out_dir>/manifest.json --form <form>
   python scripts/gzh_draft.py --manifest <out_dir>/manifest.json --check-only
   ```
   - `gzh_lint` 退出码 `2` → 按报错改**结构**（字数、加粗数、导语、来源行、卡片连排）
   - `--check-only` 的 `errors` 非空 → 按行号改**标签**
   - **最多重写 2 次**；第 3 次还不过就放弃这一篇，别硬存

6. **只存草稿，不发表**
   ```bash
   python scripts/gzh_auto.py --manifest <out_dir>/manifest.json --daily-cap 3 --publish none
   ```
   发表由 9:00 主任务的第 2 步统一做（`--from-queue`），写稿这步**不要推码**。
   - 退出码 `0` 且 `publish_state` 是「已发表」→ 成功
   - 退出码 `8` / `publish_state` 是「等扫码超时」→ 人没扫，草稿还在，**不要重写稿**，告诉用户「草稿已备好，需要重推码」即可
   - 退出码 `5` → 登录态失效，告诉用户重扫
   - 退出码 `6` → 存稿失败，贴日志尾 20 行

7. **汇报（一句话 + 关键数字）**
   例：`已发表《标题》，1042 字，形态 B，加粗 8 处，appmsgid 100000089。`
   没发出去就说清楚停在哪一步、草稿 id 是多少。

## 硬红线

- **不许**自己发挥添加原文没有的事实、数字、引语
- **不许**把「已声明原创且未授权」的文章搬原文（自动线只走原创编译/聚合）
- **不许**为了凑字数注水；宁可短，不可假
- **不许**绕过 `gzh_lint` / `--check-only` 直接存稿
- 有疑问就停下来报告，不要猜

## 常见失败与处理

| 现象 | 处理 |
|---|---|
| `gzh_prep` 说没有可用链接 | 换下一条（再跑一次 `gzh_prep`，它已把这条标掉） |
| 原文抓取失败/403 | 报告「源不可达」，不要用二手转述硬写 |
| 封面为 null | 正常，`gzh_prep` 会自动渲染中文封面卡 |
| 字数怎么都超 | 拆小标题、删重复论证；不要删事实 |
| `SKIP-SAVE-BAD-BODY` | 说明标签写错导致被压平，回第 3 步重写，别重试同版本 |
