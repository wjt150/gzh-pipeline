# 安装与换机说明

打包产物：`dist/gzh-publisher-skill.zip`（顶层目录 `gzh-publisher/`）。

## 包里有什么

```
gzh-publisher/
  SKILL.md                 技能说明书（先读这个）
  安装说明.md               本文件
  references/
    组件库.md              13 个组件片段（唯一事实源）
    排版规范.md            四条铁律 + 组件索引 + 5 种拼法
    写作规则.md            两条轨道、交付物格式
    实测约束.md            所有踩过的坑（改代码前必读）
  assets/模板/
    template.body.html     样板 html
  scripts/
    gzh_doctor.py          环境自检（换机先跑）
    gzh_source.py          备素材：抓正文 + 抽封面 + 生成 manifest
    gzh_cover.py           抽封面
    gzh_draft.py           存草稿（标签校验 + 四项闸门）
    gzh_publish.py         发表（三级：dry-run / dialog / qr）
    gzh_auto.py            编排 + 七道闸门
    gzh_cleanup.py         删草稿（默认只列不删）
    test_body_scan.py      本地单测（11 例）
    radar_*.py             选题雷达（可选）
```

## 在新电脑上装

**1. 装依赖**

```bash
# Python ≥ 3.10（必须，脚本用了 X | None 语法）
python --version

# agent-browser + Chrome
npm install -g agent-browser
agent-browser install
```

**2. 放技能**

把 `gzh-publisher/` 整个目录放到**项目级**或**用户级**：

| 目标 | 路径 | 适用 |
|---|---|---|
| 项目级 | `<项目>/.workbuddy/skills/gzh-publisher/` | 只在这个项目用 |
| 用户级 | `~/.workbuddy/skills/gzh-publisher/` | 任何项目都能用（推荐给「换电脑也要用」） |

**3. 建工作区**

技能会按这个顺序找工作区根：`GZH_WORKROOT` 环境变量 → 当前目录往上找含
`排版规范.md` / `组件库.md` / `来源清单.md` 的目录 → 当前目录。

最简单：在你的文章目录里放一份 `排版规范.md`，或者直接设环境变量：

```bash
export GZH_WORKROOT="/path/to/your/workspace"    # Windows: set GZH_WORKROOT=D:\work
```

**4. 自检**

```bash
python <技能目录>/scripts/gzh_doctor.py
```

会逐项检查：Python 版本、文档是否齐、脚本是否齐、agent-browser、登录态目录、临时目录写权限、封面工具。
**缺什么会直接告诉你，并给出修复命令。**

**5. 第一次登录（必须）**

```bash
python <技能目录>/scripts/gzh_doctor.py --login
```

会弹浏览器窗口，**用该公众号的管理员/运营者微信号扫码**。

> ⚠️ 登录态（cookie）**不能从别的电脑拷过来**：换了机器、换了 IP 都会失效，绑定的还是微信号本身。
> ⚠️ 扫码的号**必须是管理员/运营者**。用别的号扫，页面会停在「请联系管理员验证」，文章永远发不出去
> （后台可能显示 `checking:1` 但发表记录里没有，这是最容易误判的地方）。

**6. 验证**

```bash
python <技能目录>/scripts/gzh_draft.py --manifest 稿件.json --check-only
```

输出 `errors: []` 就说明能用了。

## 配置你自己的号名

封面卡左上/左下的小字来自工作区根的 `品牌.json`，代码里不写死：

```bash
cp 品牌示例.json 品牌.json
# 编辑成你自己的，例如 {"kick": "某某观察 · AI 工程", "foot": "某某观察"}
```

没有这个文件也能跑，只是封面卡少两行小字。它不进技能包，也不会进 git。

## 把整条产线搬到另一台电脑

代码可以只带技能包，但**状态数据要一起搬**（稿件、台账、选题池），否则新机器会以为「什么都没发过」。

一条命令打包：

```bash
python scripts/gzh_export.py            # → dist/迁移-YYYYMMDD.zip（含自述）
python scripts/gzh_export.py --list     # 先看会打什么
```

**包里有什么**：代码 22 个脚本、文档、模板、`稿件/`（含 body/manifest/cover/draft.json）、
`运行台账/`（ledger + notice）、`雷达/pool.jsonl`、技能本体。

**包里没有什么，以及为什么**：
- `.cache/browser-profile` —— 微信登录态。cookie 绑机器与微信号，**拷了也无效**，新机器必须用管理员微信重扫。
- `雷达/*.html` —— 历史雷达页体积大，可随时从池子重建。

**到新电脑上的顺序**：

```bash
# 1 解压到新位置，作为新的工作区根
# 2 装依赖
npm install -g agent-browser && agent-browser install     # agent-browser
# ffmpeg 也要装（封面裁剪与封面卡依赖它）
# 3 自检
python scripts/gzh_doctor.py
# 4 重新扫码
python scripts/gzh_doctor.py --login
# 5 确认队列还在
python scripts/gzh_queue.py list --json
# 6 试运行（不真发）
python scripts/gzh_publish.py --from-queue --mode dry-run --plan-only
```

如果 `稿件/*/draft.json` 丢了（比如只拷了部分文件），用台账重建：
`python scripts/gzh_queue.py sync`。台账是唯一事实源，别手改。

## 修改与重新打包

**源在项目里，包是产物。** 改完重跑一次打包脚本即可，不要手改 zip：

```bash
# 改这两处之一
#   技能本体：<项目>/.workbuddy/skills/gzh-publisher/
#   三份文档：<项目>/组件库.md  排版规范.md  写作规则.md
python scripts/build_skill.py --check    # 先看会不会缺
python scripts/build_skill.py            # 打包到 dist/
```

`build_skill.py` 会把技能目录、三份文档、模板、脚本**一起**收进包——之前漏了文档，
换机后 `SKILL.md` 让 agent 去读 `组件库.md` 却找不到，技能等于哑火。

## 已知限制

- **发表最后一步必须人工扫码**，这是平台的硬约束，绕不过（个人订阅号没有发布接口权限）。
- `gzh_draft.py` 的正文格式只支持 `section / span / strong / br / img` 五个标签，
  `<p>` 会被微信编辑器压平。第三方排版工具的 HTML 不能直接喂进来。
- 换电脑后建议先跑 `--check-only` 再真写，避免白跑一次登录态。
