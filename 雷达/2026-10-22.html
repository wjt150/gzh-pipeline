01PHP2Shell：AI 挖出潜伏二十余年的 PHP 核心 RCE，影响全球约 70% 网站，10-21 已发补丁

Wiz Research（10-21）原文 ・ 同题：OpenAI · Patch the Planet（10-21） ・ TechCrunch（10-21） ・ Simon Willison（10-21）
  • Wiz Research 披露 PHP 核心引擎的内存安全漏洞两组，编号 CVE-2026-109618 / 109619，CVSS 最高 9.2，可实现无需认证的远程代码执行与进程内存泄露，与上层框架无关；
  • 受影响版本回溯到 PHP 5.4——近十年发布的每个版本至少中一个，而 PHP 支撑全球约 70% 的网站（WordPress、Drupal、MediaWiki 等）；
  • 漏在代码里躺了十几年，卡住的是「证明可利用」这一步；Wiz 在研究中用了 Wiz Atlas、Gemini 4 Argon 与 GPT-5.6 Sol，并点名 Gemini 4 Argon 在找洞、开发利用、写检测和验证补丁上贡献关键；
  • OpenAI 侧是同一条线上的另一头：Calif 用 GPT-5.6 Sol 独立发现缺陷，OpenAI 以 Patch the Planet 牵头维护者、研究者与安全厂商做了约两个月协调，10 月 21 日 PHP 发布补丁；Simon Willison 提醒整个 PHP 8.x 线都要升。

02LiteLLM 被投毒：PyPI 上 1.107.0 是恶意版，而泄露的 GitHub token 疑似来自 Claude Code 的输出

Wiz Blog（10-21）原文
  • 10 月 21 日 11:39 UTC 恶意版 LiteLLM 1.107.0 被上传到 PyPI，13:20 被隔离；GHCR 与 Docker Hub 上的 v1.107.0 / latest / main-latest / main-stable 四个标签同样被植入，约 13:53 移除；最近的安全版本是 v1.106.2；
  • 装包后往 site-packages 根目录丢三个文件——cook.pth、cook.py、sitecustomize.py，只要 Python 解释器启动就会执行，等于常驻；
  • LiteLLM 开发者 BerriAI 的复盘指向 三名工程师的 GitHub 账号被用来发版与批准，疑似 GitHub CLI OAuth token 被窃；其中一条链路相当刺眼：他们称 Claude Code 会把用户的 GitHub CLI OAuth token 嵌进响应体，而响应体被记录进日志时，token 就落进了 LiteLLM 的日志里，攻击者再从一个意外暴露在公网的内部实例上把它捞走。

AI前线·InfoQ（10-21）原文
  • 内部研究：2025 年初至今，技术部门初级员工占比由 21% 降至 14%（相对降幅约 33%），新招员工里初级占比由 27% 降至 9%；

  • 不是简单换人：技术部门完全不写代码的员工占比一年内近乎减半，管理者提交代码的频率几乎翻倍，工程师与产品经理之比拉到约 17:1；
  • 补充口径来自招聘从业者对 LinkedIn 的分析：1680 名在册工程师入职前经验中位数 12.2 年，经验不足 3 年的只有 50 人——它的门槛本来就在资深一侧。

13数千个 GPT-Rosalind agent 并行 32 分钟，把「人工要数月到一年」的脑细胞数据分析做完了

OpenAI News（10-21）原文 ・ 同题：Hacker News 热帖（134 分）
  • OpenAI 与 PerturbAI、Scripps Research 用数千个由 GPT-Rosalind 驱动的 agent 分析小鼠全脑 CRISPR 图谱（数百万个脑细胞），32 分钟完成分析加文献解读，团队估算人工逐项做要数月到一年；
  • 分工是「一个 agent 管一个基因扰动」：分析细胞反应、检索文献、给出机制解释，最后汇成一张把基因—细胞效应—文献—机制串起来的推理图谱；
  • 量化对比很直接：同一负载下分布式 agent 引用了 700 多篇文献，单个 agent 只引 11 篇；盲测中人类专家75%更偏好分布式 agent 的报告；
  • 新线索里比较硬的两条：Tsc2 在小脑的作用显著强于 Tsc1（与结节性硬化症的小脑异常对得上），以及 DCTN1 扰动会上调胆固醇合成基因（指向 Perry 综合征）。论文在 bioRxiv，代码与图谱已开源。
待核验★★

14Andy Pavlo 谈 Agent 删库：护栏几十年前就有了，只是大家急着让 agent「能干活」

AI前线·InfoQ（10-21，据 The MAD Podcast 整理）原文
  • CMU 教授、现 ClickHouse 数据库研究副总裁 Andy Pavlo 的判断：Agent 删库不是新问题，是旧问题被重新暴露——权限与管控手段几十年前就有，缺的是「先问它干错了怎么办」；
  • 他给的做法是权限隔离 + 分支沙箱（让 agent 根本进不去生产库），而不是「坐在旁边一个个点批准」，后者在几百个 agent 的规模下不成立；
  • 顺手给了几个可引用的数：现成 text-to-SQL 方案准确率约 60%，某大银行花数年、数百万美元建语义层才做到 99.5%；LLM 调数据库参数 15 分钟能到「传统方法几小时训练」的约 85% 水平；
  • 更刺的一句：CMU 数据库课程项目在 Opus 4 之后「几乎不需要提示就能全做完」，且超过 60% 的开源数据库已出现 agent 参与的 commit。

15Cloudflare 开源 Clef：不生成文本、只输出选项概率的「决策模型」，9B 版中位延迟 38.8 毫秒

AI前线·InfoQ（10-21）原文
  • Cloudflare 在生日周发布开源权重模型 Clef：输入「状态 + 带类型问题的 schema」，一次前向推理就给出每个选项的概率，不生成自由文本、不需要解析输出；
  • 两个尺寸：270 亿参数多模态版（文本 / JSON / 图像 / 视频，延迟 209.3 毫秒）与 90 亿的 Clef-Flash（中位 38.8 毫秒，专为延迟敏感场景）；上下文 64k，比它兼容的 Typesafe Jev System One（32k）大一倍；
  • 定位是插在 agent 决策路径中间的「分类器」——派单、升级、转人工；模型跑在 Cloudflare 边缘 GPU 上，权重已在 Hugging Face 可下；
  • HN 上的讨论不客气：有人说「这不是新范式，只是第一个愿意停下来摘果子的人」，也有人提醒「公开基准很容易做手脚」，真正该测的是它知不知道该放弃判断。
