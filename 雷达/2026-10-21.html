01DeepSeek 开源自研推理框架 DeepInfer，连同生产级 token 组件 deepseek-recipe

新智元（10-21）原文 ・ 同题：DeepSeek 官方公众号（10-20，经 AIHOT 收录，未打开核验）
  • 仓库 github.com/deepseek-ai/DeepInfer 与 deepseek-recipe 同时放出，后者把 OpenAI Chat Completions / Responses 与 Anthropic Messages 三种 API 格式统一成同一种对话格式；
  • 官方线上统计：平均每请求输入 77K Token，首字约 400 毫秒，生成 230 token/秒（写代码时 300），平均 96% 的输入命中 KV 缓存；
  • 部署把 Prefill 与 Decode 拆开——Prefill 用 8 卡机、Decode 用 64–128 卡超节点，最小部署单元为 64 卡 Prefill + 64 卡 Decode；支持名单上有英伟达 SM100 与华为昇腾 950。
