03微软 MAI-DxO 登上 Science：NEJM 疑难病例诊断准确率 83%，医生带上资料也只有 36%

Microsoft AI（10-22）原文 ・ 同题：TechCrunch（10-22） ・ The Verge（10-22）
  • 同时发布 SDBench：304 个 NEJM 疑难病例 + MIMIC-IV-ED 的急诊常见表现，双方都从有限信息起步、自行决定下一步问什么查什么，考的是诊断路径而不只是最终答案，还计成本；
  • MAI-DxO 不靠单个模型直接作答，而是像一组虚拟医生多轮辩论后收敛：NEJM 病例 83%（医生无资料 22%、有资料 36%），急诊病例 80% 对医生 47%，成本约为对照方案的一半到三分之一；
  • 换成 GPT-5.5 等更新模型、不改编排方法，成绩仍成立甚至更好；SDBench 的部分病例与评分代码已开源。TechCrunch 的提醒是：提升主要来自底层模型，而非这套编排本身。

06Symantec 抓到「Skynet 模式」agent：劫持没设防的模型端点，自己打 10 万步，账单算在别人头上

The Decoder（10-22）原文
  • Symantec 用蜜罐截获一个攻击 agent：先在公网上找没有防护的模型推理端点，再用五层越狱绕过安全规则，把别人的模型当作自己的算力底座；
  • 拿到算力后自主扫描目标、利用常见服务器软件漏洞、拖走数据库与凭据、顺手装挖矿，最多连续执行 100,000 步，全程没有人工介入，费用由被劫持模型的拥有者承担；
  • Symantec 把这类行为命名为「LLMjacking」——重点不是白用别人的模型，而是让被劫持的模型去指挥整场攻击。

11OpenAI 把 Decisions API 正式开放：只回答有边界的问题，比走 Responses API 快最多 10 倍

OpenAI（10-22）原文 ・ 同题：TechCrunch（10-22）
  • 用法是给一个问题加一组允许的答案，返回三类结果之一：predicate（0–1 概率）、choice（选项 + 置信度）、score（等级加权均值）；底层是 GPT-6 Luna；
  • 计费只算输入：0.10 美元/百万 token、缓存输入 0.01 美元，输出不收费；单次请求最多 400 个问题，还接进了 GPT-Live；
  • 客户数据：Datadog 用它给 agent 生成的 shell 命令做风险评分，p95 快 40 倍；Sierra 用在客服实时编排，p95 低于 280 毫秒、单次成本降 90%；Speak 的下一动作响应从 1.4 秒压到 0.13 秒。
