## 为什么先发这个

新号最缺的不是内容，是**有人愿意说话**。一图一问的门槛最低：
不用读完一千字，看图三秒就能选一个。

而这三个平台的互动机制完全不同：

| 平台 | 能不能讨论 | 怎么用这张图 |
|---|---|---|
| **小红书** | ✓ 评论区主战场 | 首图发这张，正文写自己的答案 |
| **知乎** | ✓ 回答+评论 | 当「想法」发，或答「用 AI 省下的时间」相关问题 |
| **公众号** | ✗ 无留言功能 | 只做沉淀，文末引导私信 |

**公众号没有留言功能**（后台 `appmsgcomment` 路由 404，2018 年后注册的个人号都没有），
所以别在公众号等评论——等不到。真要沉淀，发「图片消息」，占一次群发配额。

## 一、小红书版（首发）

**标题**（20 字内，带具体物）

```
省下的三十个小时，我一分钟没学新东西
```

备选：
- `AI 让我每天快一小时，然后我把它刷掉了`
- `越省越忙，是效率提高的默认结局`

**正文**（2026-11-04 重写，去运营腔：不用 ①②③④，用场景开头）

```
上周三下午，我对着周报的空白框坐了七分钟。
光标一直在闪。
不是没东西写，是懒得写。

后来我把这周干的事敲给 AI，让它按"做了什么、卡在哪、下周计划"三块整理。
四十分钟的活，十分钟完事。

省下半小时。

这样的半小时，我一天能攒一个多。写周报、整理会议记录、把老板的语音转成要点。
一个月下来，大概三十个小时。

三十个小时，我以为我会拿去学点东西。

实际上，我拿去刷手机了。
还有一部分，变成了"既然你快了，那就多做两件吧"——
上个月我接了两个本来会推掉的活。

所以想问问：你省下来的那部分，去哪了？

我猜最多的是最后一种。因为效率高上去之后，
老板看到的往往不是"你更快了"，是"你还能再接一点"。

说说你的。我最想听那种"越省越忙"的。
```

**话题标签**

```
#AI工具 #效率工具 #职场日常 #打工人 #AI办公 #时间管理
```

**发布注意**
- 首图就是这张卡，别裁
- 正文第一行要能独立成句（信息流只显示前两行）
- 评论区自己先留一条：「我先说：我选 1，而且很理直气壮。」——**第一条评论决定后面的人敢不敢说真话**

## 二、知乎版

当「想法」发，或找这类问题回答：

- 「普通人用 AI 真的能提高效率吗？」
- 「AI 时代，个人效率提升的意义是什么？」

**开头**（知乎要的是判断，不是提问）

```
先说结论：AI 确实省时间，但省下来的时间不会自动变成你的。

我用 AI 三个月，每天大约省一个半小时。
这九十分钟没有变成学习，也没有变成休息，
它被"既然你快了，那就再多做一点"吃掉了。

这不是 AI 的问题，是效率提升后的默认分配机制。
```

## 四、后续可以接着问的（做成系列）

一个问题一张图，成本低、可持续：

1. AI 替你省下的时间，你拿去干什么了？（本篇）
2. 你会告诉同事你在用 AI 吗？
3. 你上一次因为 AI 生气，是什么时候？
4. 有哪件事你试过让 AI 做，最后发现还不如自己干？
5. 如果明天所有 AI 工具都收费，你第一个续费哪个？

第 2、4 题争议最大，留着在粉丝多一点的时候发。
