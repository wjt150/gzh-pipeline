# 公众号产线

把「选题 → 编译 → 排版 → 存草稿 → 推到二维码」做成一条可复现的流水线，每天自动出一篇，人工只负责扫一次码。

不是内容农场工具：**选题要过星级门槛，宁缺毋滥**；每篇都标注信息来源，不搬运未授权原创。

## 它解决什么

人工运营公众号最耗时的不是写，是「找料 + 排版崩 + 发布流程」。这个项目把三段都固化了：

- **找料**：雷达抓 15 个源，按事件聚簇，打 ★1–★3；选稿器按可解释的公式排序，只放行 ★3
- **排版**：13 个组件 + 5 种形态，全部内联样式，专治微信公众号「`<p>` 被压平」
- **发布**：浏览器自动化点完「发表」前的所有步骤，最后一步留给人扫码

## 关键约束（都是实测出来的，不是猜的）

| 约束 | 说明 |
|---|---|
| **每篇发表都要扫一次微信验证码** | 群发开关、定时发表、连发复用四条路全试过，绑的是「发表」动作本身，无法绕过 |
| **个人订阅号每天 1 次群发通知** | 所以一天只发 1 篇，其余草稿排队 |
| **正文只允许 5 个标签** | `section / span / strong / br / img`。用 `<p>` 会被编辑器合并压平，加粗和样式全丢 |
| **发表后 appmsgid 会变** | 所以核验不能按 id，要按「发表总次数 +1」 |
| **封面必须 2.35:1** | 910×383。原文 `og:image` 常见 1.9:1，偏差 19% 会被裁掉核心信息 |

## 结构

```
scripts/
  pick_one.py      选稿：S = 100×(0.42R+0.18Q+0.15F+0.15H+0.10M) − 惩罚，阈值 68
  gzh_prep.py      备稿：选稿 → 抓原文 → 裁/生成封面 → 建目录 → 写简报
  gzh_covercard.py 源上没图时，渲染中文封面卡（HTML → 截图，字绝对清晰）
  gzh_lint.py      内容级检查：字数 / 加粗数 / 导语 / 来源行 / 卡片节奏
  gzh_draft.py     存草稿：标签白名单校验 + 保存前四项闸门
  gzh_publish.py   发表：推到二维码 → 等扫码 → 点确认 → 回发表记录核对
  gzh_auto.py      编排 + 语义化退出码 + 进程锁
  gzh_queue.py     稿件队列：FIFO 排序、过期清理、台账重建
  gzh_state.py     draft.json + ledger.jsonl 的唯一写入层
  gzh_export.py    打包迁移（含状态数据，不含登录态）
  gzh_doctor.py    换电脑先跑：环境自检
```

设计上有两条反复验证过的原则：

1. **台账是唯一事实源**。`运行台账/ledger.jsonl` 只追加；`稿件/*/draft.json` 是它的投影，丢了能 `queue sync` 重建。
2. **闸门在开浏览器之前**。标签错、今天已发、这篇已发，都在本地拦掉，不浪费一次登录态。

## 快速开始

```bash
python scripts/gzh_doctor.py          # 环境自检
python scripts/gzh_doctor.py --login  # 扫一次码（管理员微信）
python scripts/gzh_queue.py list      # 库存与今日状态
python scripts/pick_one.py --explain  # 看今天为什么选/不选某条
```

需要 Python ≥ 3.10、`agent-browser`、`ffmpeg`。不依赖任何 pip 包。

## 关于「仓库里没有稿件和台账」

`稿件/`、`运行台账/`、`雷达/pool.jsonl` 都在 `.gitignore` 里，**刻意不跟踪**。

原因不是隐私，是**正确性**：这些是状态数据，如果跟着 git 走，切换分支时会一起被切回去——
台账一回退，闸门就会以为「今天还没发过」，同一天可能发两篇。状态漂移是这类系统最难查的 bug。

数据只存在于工作目录，备份用：

```bash
python scripts/gzh_export.py     # 打包代码 + 稿件 + 台账 + 选题池（不含登录态）
```

代价是 `git clone` 拿不回历史稿件，得靠迁移包。

## 设计文档

- `组件库.md` —— 13 个组件的 HTML 片段（唯一事实源）与使用条件
- `排版规范.md` —— 四条铁律、组件索引、5 种形态拼法
- `写作规则.md` —— 两条轨道（编译 / 转载）、交付物格式
- `选题判断标准.md` —— 收什么、剔什么、星级怎么打
